# Security policy

This tap only installs Engineering Runtime from its published releases, and
checks each archive against the release's SHA-256 checksums. Security problems
in the formula, the archives it installs, or `engrt` itself are handled under
the [engineering-runtime-releases security policy](https://github.com/engineeringruntime/engineering-runtime-releases/security/policy).

**Do not open a public issue.** Report it privately:

1. **On GitHub (preferred):** [Report a vulnerability](https://github.com/engineeringruntime/engineering-runtime-releases/security/advisories/new)
   in the releases repository.
2. **By email:** [support@engineeringruntime.com](mailto:support@engineeringruntime.com?subject=Security%3A%20),
   with a subject that starts with `Security:`.
